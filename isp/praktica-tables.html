Общие требования к оформлению таблиц по ГОСТ 7.32-2017

Таблица в текстовом документе — это способ структурированного представления числовых данных, характеристик и справочных сведений. При оформлении таблиц по ГОСТ 7.32-2017 соблюдают следующие правила:

  • таблица размещается сразу после абзаца, в котором на неё есть ссылка;
  • каждая таблица нумеруется сквозной нумерацией и получает подпись «Таблица N — Название», размещаемую выше таблицы слева без точки в конце;
  • заголовок таблицы пишется с прописной буквы, переносить название таблицы на следующую строку заголовка нежелательно;
  • при переносе таблицы на новую страницу строку с заголовками столбцов повторяют, а над продолжением пишут «Продолжение таблицы N»;
  • текст в ячейках выравнивается по ширине или по центру, числа — по правому краю;
  • основной шрифт таблицы может быть меньше основного текста (кегль 12–13), но единообразно во всём документе.
Инструменты: работа выполняется в Microsoft Word, Google Docs или Яндекс Документах. Команды создания и форматирования таблиц различаются по названиям, но принципы одинаковы: «Вставка → Таблица», «Работа с таблицей» / «Макет».
